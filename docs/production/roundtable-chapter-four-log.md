# 円卓会議ログ：第三章でやること／第四章の導入（2026-11-22）

裏会議（楽屋話）の素材として残す記録。**決定ではない**。採用はユーザーの回答で決める。各参加者は互いの意見を見ずに独立に検討した。実プレイはしていない。人物の独白はすべて仮想。

## ユーザーが示した前提
- 新大陸には大きな商業都市を持つ国があり、元英雄の王が治める。王は魔王の邪気にやられ「知識狩り」をしている。
- 実は王は妻と子を人質に取られ、生かす代わりに魔王と契約してしまった。
- 街はゾンビのように寂れ、所々ディストピア化。ゾンビのような者が次々向かってきて戦闘になる（でも本来は街の人間）。
- 追加：四天王の二人目として「道化師エヌコイールイーチ」を出してもよい。

## 各参加者の要点

### 肯定派
- 第三章と第四章は「作る町（職人の町）と売る都（王都）」。職人の噂「王都の注文が途絶えた」「王都へ行った弟子が戻らない」で伏線。
- ゾンビ化住人は「名前（身元）を奪われた人」にすると、世界の規則・ハンナとの一貫性・認証のテーマが一度にそろう。勝つと「名前を思い出した」。
- 道化師：王都の関所で通行人を一人ずつ呼び止め、そのたびに名簿を取りに走る＝N+1。主人公が「まとめて持ってくれば」と気づく（with）。倒されず「本番の身元検めへどうぞ」と退場。
- ボヤキ：「ゾンビを殴って救うって、要するにログイン画面なんだよね。パスワードを思い出させてあげるRPG、世界一優しい」／「N+1 の道化師、問い合わせのたびに玉を一個ずつ投げ上げるジャグラーにしたい。with で全部まとめて投げたら拍手」

### 中立派
- 最優先の食い違い：ゾンビ化を四天王の仕業にすると規則違反、魔王の仕業にすると主役が魔王になる。混合案：王本人＝魔王の邪気、住人＝身元を奪われた。
- 職人の町は王国の辺境の自治の町。王都の噂は1〜2人までに抑える。
- 道化師の枠は3案：A 断縁卿と入れ替え（つながり、学習は合う）／B 仮面卿と入れ替え（名前の由来とずれる）／C 四天王ではなく導入の中ボス（既存の決定を最も崩さない）。
- ボヤキ：「ゾンビの出どころを一行決めないまま村を三つ描き始めると、全員の台詞を書き直すのは私なんですよ。」／「四天王が5人目を雇い始めたら、それはもう会社です。」

### 否定派
- ゾンビ化は規則と真っ向からぶつかる。代案：仮面卿に身元を奪われた「名無し」が「お前は誰だ」と詰め寄る。照合に正解すると名前が戻り座り込む。ハンナほど重くしない。
- 職人の町が知識狩りの国にあるなら真っ先に狩られる矛盾。辺境の自治の町にし、噂だけ出す。
- 王・妻子・契約は未確定の設定（騎士の正体・両親の生死）を示唆しやすい。王と騎士・両親の関係は肯定も否定もしない。
- 作業量が破綻する。王都1つ＋宿場1つに絞り、進行判定の共通化を先に。
- 知識狩りは認可に聞こえる。第四章は「あなたは誰か」だけに絞る。
- ボヤキ：「ゾンビの街、絵面は最高。でもそのたびに魔王が残業してたら、四天王の出番がないんだよ」

### ユーザー代弁者
- 浜辺の先は一本道。地図案内は今いる大陸で切り替える（今の地図は旧大陸固定）。
- 明るい職人の町→暗い王国の落差。王国の中にも息抜きの「安全な灯り」（隠れ私塾・酒場）。救った住人が戻って店が開く進行感。
- ゾンビ住人とは「正気に戻す」戦闘。エンカウントは街路だけ。
- 道化師は「明るい顔で怖い」独演の役。敵の側から次の目的地を煽る案内役も兼ねる。名前からN+1を連想して「問題で出ないの？」と迷わせない。
- ボヤキ：「ゾンビの街は雰囲気最高だけど、プレイヤーの心が先にゾンビになったら意味ないんだよね……。」／「道化師が一番面白いと、王様の悲劇が前座になっちゃうんだよなあ。」

### AIの代弁者
- 新マップは海底方式（レイアウトJSON＋数十行）で1枚ずつ足せる。最初は「港町1枚＋最初の戦い」で、第三章序幕と同じ大きさ（クエスト1本・step4つ・マップ1枚・ボス1体）。
- ゾンビ住人は既存画像の灰色版で0枚。救ったら同じ座標に町の人を置き直す処理1つ。道化師の通せんぼはヘドロの主と同じ仕組み。
- 画像は導入だけで最小8枚（道化師3、地形チップ3〜4、小物1〜2、イベント絵1〜2）。
- 進行判定（第二章専用）の共通化を先にしないと、App.tsx の分岐が章ごとに増える。
- ボヤキ：「王様が元英雄で人質つき、と設定は盛り上がるけど、こっちはまずApp.tsxにある第二章専用のif文をはがすところから始まるんだよな」

### 先生
- 第四章（認証）で教えるのは4つ：Auth::attempt とハッシュ／セッションと Auth::user()・regenerate／middleware('auth')／第三章の1対多と組み合わせた総合。Gate・Policy は第五章。
- 「知識狩り」と認証を重ねない（認証＝弾圧・監視という誤った印象を残す）。仮面卿のなりすまし＝照合のない認証、などで重ねる。
- N+1 は第三章（リレーション）の延長。第四章の導入を「第三章のふり返り＋N+1」の小幕にし、道化師は門前の前座（四天王ではない道化）にするのがおすすめ。導入は10問前後：回数を数える2問、with 4〜5問、結果は同じかの判断1〜2問、1対多の復習3〜4問。
- 名前の読み：「N個＋eel＋each」とも読める。each で回すたびに1本ずつ釣り上げる＝N+1。
- ボヤキ：「知識狩りの国で知識を教えるの、先生としては肩身が狭いんだよねえ」／「N+1を教えるのに道化師を1人雇ったら、部下を毎回1人ずつ呼び出すから結局N+1人来たよ」

### 作中人物（仮想の独白。王・王妃・子の名は仮）
- 主人公：「台帳が戻って、宛先に王国の名が浮かんだ。父さんが頼った相手が、知識を狩る王？……確かめるしかない。でも、まずは目の前の人だ。」
- 住人：「……ワタシハ、ダレ。名札が、合わない。扉が、開かない。お前の名前を、くれ……」
- 王（仮：レオニス）：「余は剣で国を救った。だが、帰ってきた妻の顔が本物か、余には確かめる術がない。知恵を持つ者は嘘を作れる。……ならば、知恵ごと狩るしかなかった。」
- 子（仮：ルカ）：「父上は僕の顔を見ても、すぐには抱きしめてくれなかった。……僕が本物だって、どうやったら分かってもらえる？」
- 仮面卿（仮）：「契約？ 私はそんな野暮なものは結ばない。王が怯えるのは、私が王妃の声で囁くからさ。」
- 断縁卿（案）：「海の向こうの王は、縁があるから縛られた。縁さえ断てば、誰にも人質など取れぬ。」
- 道化師エヌコイールイーチ：「お一人様ずつ、ご案内〜！ 門番さん、この人は誰？ 次の人は？ そのまた次は？ 百人並べば百回聞く、これぞ道化の大行列！ まとめて聞けば早い？ そんなの、つまらないじゃないか。」
- ボヤキ：道化師「楽屋入りにも名前の確認が百回。……ああ、これ、ボクの持ちネタだった。」／仮面卿「私の出番、名前に（仮）が付いたままなんだがね。身元を奪う役が、自分の名前を持っていないとは。」／王「元英雄で、人質を取られて、弾圧までして、それでも嫌われるなと？ 台本が重い。」

## 道化師についての補足（否定派）
- 名前の読みは「N個要る each」「N・call・each」「N・コイル・each」のどれか未確定。台詞で「エヌ・プラス・ワン」と言わせるかも要決定。
- 枠がぶつかる：二人目「つながり」には断縁卿（案）がいる。おすすめは道化師が断縁卿（案）に置き換わる案。鋏と糸のモチーフは双子チョキ/ホツレに残せる。
- 出番は第三章の終幕〜第四章の導入をまたぐ位置。関所が一人ずつ名簿倉庫を往復する（N+1）せいで、城門前に虚ろな行列。住人の一部は「待たされ続けて疲れ切った人の群れ」として描けば魔物化ではない。
- 導入で学ぶのは (1) 1対多のふり返り (2) N+1 と with() (3) 認証が必要になる理由（行列が解けると、名乗った者が本人か誰も確かめていないと分かる＝仮面卿が入り込む余地）。
- 道化師は面白半分に関所を混乱させただけ、仮面卿はそれに便乗した（四天王は群れない）。王の契約・妻子は仮面卿側に残す。
- ボヤキ：「道化師が一人ずつ呼び出すたびに、作業量もN+1で増えていくんだよな。」
