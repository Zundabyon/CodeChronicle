# 第三章 序幕「海底の古道」設計 v2

対象は配置JSON・設計・検証の3ファイル。ゲーム側の組み込みと実画面の検証は担当側で実施する。生成時の配置が正本で、保存済みの石板・敵・宝箱・帰還点・ボスIDは維持する。

## 接続と進行

父の古い依頼書の宛先を確かめるため、自分の意思で海を渡る。[第三章計画](chapter-three-plan.md)の導入を維持し、両親の生死を確定せず「縁の台帳」はここでは教えない。石灯の村の既存建物 `village-ledger-house` → 地下書庫 → 入口 [8,104]。入口南隣 [8,105] の階段と [9,105] の帰還灯用床を維持する。第二章クリア後の開通・村との遷移は実装側の管理。

帰還点は2個。訪問で有効になり、地下書庫前室 [8,104] へ戻る。再利用時は対応する `resumeLanding` に任意で戻る。浜辺の出口 [40,4]・制作中看板 [44,4] とその操作位置 [43,4] は維持する。新しい街への遷移はこの配置設計では追加しない。

## 坑道の形と区画

81×111、64pxセル、座標は左上原点のx東・y南。地形は `.` と `#` だけ。主導線は基本幅1、海窓のみ一部幅2。分岐の合流、石板の3×3の窪み、泉、ボス広間、浜辺は局所的な拡幅。一本の幅3の大通りを廃止し、段違いの屈曲と11本の細い迂回坑、短い空の行き止まりと3本の宝箱支路を組み合わせる。

## 正解の道を読む

`mainRoute` は任意戦闘を避けて進める連続した案内線。`waypoints` はその曲がり角。書庫の三本傷→浸水の細い水筋→船腹の古い線路→捨て場の引きずり跡→海窓の線路→泥に埋もれた壁の三本傷、と区画ごとの連続した手がかりで追える。分岐では案内線側の壁に同じ印を続ける。単独の鎖・目・水滴は道案内にせず、不安を誘う周辺演出にする。これらの連続手がかりの描画は実装担当への指示であり、地形だけで表示済みとはしない。

最短 418 歩（従来286歩、上限429歩）。手がかりに沿う主導線は 452 歩、曲がり角 54 個。広間・浜辺を除く導線の幅1〜2の比率 80%。短い迂回坑は同じ区画に戻り、区画を丸ごと飛ばす接続やボスへの裏口は作らない。

## 敵と寄り道
