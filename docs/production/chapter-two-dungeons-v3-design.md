# 第二章 記憶ダンジョン4つ v3設計

状態：設計提案。ゲーム未組み込み・未プレイ検証。`src/` は変更しない。座標は0始まり、x東・y南。

## 設計の要点

v2の「同じ縦積み5室＋パターン順送り」を廃止し、床を作るアルゴリズム自体を4種類に分けた。Createは幹から枝が伸びる樹状路、Readは水路で隔てた島と細橋、Updateは高低差を往復する九十九折、Deleteは交互に欠けた同心環である。5実習室の学習順と既存IDは維持する。

## 共通契約

各室は入口兼帰還点→必須解説→探索→問題NPC→扉の順。扉と必須解説に迂回なし。任意解説は脇道の奥。第3室は敵なし＋泉。敵は既存3種×4体（12体）で、半径2の行動範囲が主導線・必須解説・扉・帰還点・泉へ重ならない。再入場は開扉数0〜5の6状態から `min(N+1,5)` 室入口へ着地する。

凡例：`#`壁、`.`床、`D`扉、`T`問題NPC、`M`必須解説、`o`任意解説、`R`帰還点、`S`泉、`e`敵原点、`G/V/A`既存NPC、`I/X/Z`入口・出口・祭壇。
