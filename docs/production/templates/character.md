# 人物・生物の固有設定ひな形

共通の制作手順や採点・保存契約をここへ複製せず、対象の情報と正本への参照を埋める。記録用であり、アプリに自動読込される形式ではない。

| 項目 | 記入する内容 |
|---|---|
| 対象 | 既存IDまたは新規案、名前、主分類、役割。種類と配置個体を区別 |
| 確定特徴 | 体型・髪・衣装・装備・配色・顔の有無など、他用途でも維持する特徴 |
| 物語 | 確定した設定の正本、未確定の事項 |
| 参照 | 人物同定・絵柄・構図のどれに使うかを画像ごとに記す |
| 必要用途 | 会話画像、静止マップ、歩行、戦闘など。各共通仕様へのリンク |
| 対応状況 | 用途ごとに素材/登録/確認があるか。未対応を明記 |
| 可変部分 | 表情・ポーズ・場面など変更できる範囲 |
| 登録先 | 利用するコード/データ、既存の専用分岐、保存IDへの影響 |
| 制作履歴 | 採用・不採用・旧版と確認結果へのリンク |
