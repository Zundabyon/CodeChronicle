# タイトルの発光とオブジェクトの動き

2026-11-05。採用：元の静止背景を維持し、ランタンと門の紋様に控えめな発光を重ねる。全景GIF・動画は追加しない。

## 方針と実装

ユーザーと円卓で「動きを足す方向は採用、まずランタンと紋様、光粒・川・マントは次段階」とした。ユーザーの追加指示により、対象専用の演出だけでなく、他のオブジェクトにも使える動きの部品と確認用ハーネスを用意した。

仕様は[オブジェクトの動き](../production/uses/object-motion.md)、[背景](../production/uses/backgrounds.md)、[画面・操作](../production/presentation.md)を参照。型・再生ポリシーと対象の設定は分ける。

- [ObjectMotion](../../src/motion/ObjectMotion.tsx)：HTML/SVGの装飾に発光・揺れを適用。秒・位相・強さを指定。
- [titleMotion](../../src/titleMotion.ts)：タイトルの元画像寸法・2つの対象の形と設定。背景画像は既存のものを再利用し、新しい画像生成・加工はしていない。
- [ArtworkMotionLayer](../../src/motion/ArtworkMotionLayer.tsx)：元画像の座標を、画像のcoverと同じ切り抜きで表示。初回計測まで追加の光は非表示。
- 停止操作は既存フッターと同じ行。低いPC画面で開始ボタンを押し出さず、背景だけを停止できる。
- 手動設定は冒険・音設定と別に保持。モーション軽減・非表示タブ・背景ロード失敗時は静止し、タイトルを離れれば購読を破棄。
- `npm run dev:motion`は部品の発光・揺れ、強さ・周期、タイトルへの配置を確認するdev専用画面。本番ビルドへハーネスのUIは含めない。

同じ背景を使い、source座標を登録する形で再利用する。オブジェクトの自動分割、実際のランタンの物理的な振り子、歩行・戦闘の演出統合を完了したものではない。スマホでは元の切り抜きに従うので、画面外のランタンの光を別位置へ移すことはしない。
