# キャラクターの会話用画像

人物・敵・生物を会話で見せる画像の共通制作仕様。騎士用や主人公用に手順を複製せず、この仕様へ対象の[固有設定](../characters.md)を組み合わせる。対応状況は規約あり。汎用の人物画像レジストリは未実装。

## 共通入力

対象ID、固有特徴、顔を見せる/隠す条件、表情、向き、胸像/全身の用途、参照画像と役割、実際の表示枠。人物同定用と絵柄用の参照を区別し、目視して実際に生成入力へ渡す。

## 制作と採用

- [共通美術基準](../../art-direction.md)と既存肖像に描き込み・輪郭・陰影を揃える。会話用の大きさへ小さな歩行絵を引き伸ばして済ませない。
- 胸像なら頭部・髪・耳・兜・両肩を収め、切る位置を意図して指定する。体型や頭部が人型でない場合もその対象を読める構図にする。
- 透過/背景付きは用途に合わせて明示する。透過なら実alphaを確認し、外側の背景残りや切り抜けを点検する。
- 服・武具・髪・顔の有無などの確定特徴を他用途と一致させる。表情差分は確定した元絵を参照し、個体の同一性を維持する。
- 大きな原画だけで採用せず、実際の会話枠とスマホの枠で既存肖像と比較する。

## 登録と確認

[CharacterPortrait.tsx](../../../src/CharacterPortrait.tsx)と利用先のface対応、専用分岐、CSSを確認する。原寸・cropは実測し、保存する実画像は版を分ける。描画コードの値が正本で、この仕様に全対象の寸法を固定しない。一般人物はfaces atlas、騎士は別componentという現状を前提に登録先を確認する。

マップとの人物同定、実際の会話呼び出し、名前・顔の一致、頭部/装備の欠け、PC/スマホの縮小表示を確認する。生成プロンプト・参照・実寸・採否は[履歴](../templates/record.md)へ。過去の[騎士肖像](../../art/knight-portrait-v2.md)は参考記録で、すべての人物に兜や同じポーズを要求するものではない。

## 再利用する指示の形

「会話用途と表示枠」＋「対象の固有設定」＋「表情・向き・構図」＋「共通美術基準」＋「参照の役割」＋「維持する特徴/変更する部分」から具体的なプロンプトを組む。対象の情報がないままテンプレートの語だけを生成ツールへ渡さない。
