# 第二章 新規画像の生成依頼（ChatGPT／Codex向け）

依頼者：Claude（依頼の準備と、受け取った後の組み込み・実表示の確認を担当）／生成担当：ChatGPTまたはCodex
前提資料：[第二章の幕構成：合意した構成案](chapter-two-acts-handoff.md)、[共通美術基準](../art-direction.md)、[game-art Skill](../../.agents/skills/game-art/SKILL.md)

生成担当が行うのは、画像の生成と、実際の指示・参照・採否の記録（[履歴ひな形](templates/record.md)、`docs/art/`）まで。`src/` への登録、表示の確認、`npm run check:art` はClaudeが行う。人物の設定は、この依頼に書いた範囲で確定しているものとして扱う。依頼にない過去・正体・特徴は付け足さない。

## 共通条件

- 細かく可愛いSFC時代のRPG風のドット絵。既存画像と同じ密度・輪郭・陰影にそろえる。「pixel art」と指定するだけで済ませない。
- 主光源は左上。上面と左上の稜線を明るく、右下と接地面を暗くする。
- 透過の指定がある画像は、実際のalphaを確かめる。背景の残り、切り抜けの欠け、隣のコマの混入がないこと。
- 文字・ロゴ・数字を画像に描き込まない。担当の印は記号で表す。
- 暴力や流血の描写はしない。悪レンジャーは「可愛げのある残虐系」で、怖さは無邪気な表情で出す。

## 人物の固有特徴

### 記録卿グラフィウス（四天王の一人、「記録」を司る）

- 長身で細身の貴族。青白い顔に冷たい目、整えた髪。冷静で、人を見下している。
- 装い：インクのような黒〜濃紺の長いコートに、羊皮紙色の裏地と金の縁取り、高い襟。赤いインクの染みのような差し色。
- 持ち物：大きな羽ペン（武器として構える）と、鎖のついた巨大な帳簿（宙に浮かぶか、腰に下げる）。
- 避けるもの：紫を主色にしない（ケシや騎士と被るため）。魔物のような異形にはしない。人の姿の悪役にする。

### CRUD戦隊 悪レンジャー（4人共通）

- 戦隊ものの雰囲気を持つ、そろいの短い上着とスカーフ。顔は見せる（表情が要るので、全面マスクにはしない。ゴーグルやバイザーを額に上げる程度ならよい）。
- 胸に担当の記号を付ける（文字は使わない）：Readは目、Createは光の粒（増える印）、Updateは渦巻く矢印、Deleteはバツ印。
- 色は担当のダンジョンの基調色に合わせる：Read青 `#93c9ff` 系、Create琥珀 `#eebd71` 系、Update翡翠、Delete紫。
- 体格は子ども〜少年少女で、可愛げがある。

| 人物 | 特徴 | 持ち物 |
| --- | --- | --- |
| ノゾミ・ブルー（Read） | おしゃべりないたずら好き。片目にレンズのような飾り | 大きな虫眼鏡 |
| ツクネ・アンバー（Create） | 何でも作りたがる。ポケットから紙の人形がはみ出している（偽の住人は「中身のない紙の写し」） | 大きな判子と紙の束 |
| ヌリエ・ジェイド（Update） | わがまま。服に絵の具の跳ね | 大きな絵筆とバケツ |
| ケシ・パープル（Delete） | 4人の末っ子で、いちばん小柄。無口で眠たげ。フードをかぶる | 杖の先に大きな消しゴムのような塊 |

### フミ（石灯の村の記録係オルの孫）

- 10歳前後の少女。三つ編み。インクで汚れた指先。
- 小さな帳面（名簿の控え）を胸に抱えている。
- 服は山の村らしい落ち着いた暖色（黄土・茶・くすんだ赤）。レンジャー4色と被らないこと。
- 参照：既存の村人と同じ世界の住人に見えること（`faces.png` の素朴な服装の人物たち）。

## 受け入れ条件（Claudeが確認する）

- 指定の寸法・透過・保存先・ファイル名どおりであること。`npm run check:art` に通ること。
- 会話用・マップ用・戦闘用の3つで、同じ人物だと分かること（色・髪・持ち物・記号が一致すること）。
- 既存の画像と同じ表示倍率で並べて、描き込みの密度・輪郭・陰影がそろっていること。
- ケシの2コマ、フミの2コマ、帰還点の2枚、灯りの元絵と差分が、それぞれ同じ対象に見えること。
- 謎の騎士と、どの新しい人物も見分けられること。
