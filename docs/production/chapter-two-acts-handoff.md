## 構成

- 幕は2-1 Read → 2-2 Create → 2-3 Update → 2-4 Delete の順にする。現行のR→U→C→Dから変更する。
- 狙いは、各CRUDを村の困りごとに結びつける物語のつながりと、学んだ流れを別の題材へ当てはめる応用力。全体が長くなることは許容する。
- 既存のダンジョン・部屋・扉・敵の仕組みを幕の舞台として使い回す。
- `ledger-delete-transfer`（認可と対象照合）は第二章から外し、第三章の候補として保留する。

### 世界の規則：記録と記憶

名簿は村人の記憶の手がかりで、人そのものではない。行が正しい形に戻ると、その人への記憶の糸がつながる。行を消しても人は消えず、名前を呼ばれなくなるだけ。消した行は戻らないので、章末の名簿の復元は、裂かれる前の欠片と控えから行う（2026-11-12にユーザーが採用）。

### 幕ごとの因果

各幕で、レンジャーの技の被害を、その幕で学ぶ正しい操作で元に戻す。困りごとは技の被害そのものにする。フミを2-1・2-2・2-4の当事者にすることはユーザーが採用した。表の各セルの細部は、台本作成時に調整する案。

| 幕 | 技 → 被害 | 困りごと | 学ぶ操作 | 回復 | フミの状態 |
| --- | --- | --- | --- | --- | --- |
| 2-1 Read「読めない控え」 | ノゾミが別人の記録を見せる。記録自体は無事 | フミが控えから家族を探せない | `index` で一覧 → IDで `show` | 回復ではなく「正しい行を見つけた」演出。データは何も変わらない | 家族の行を見つけ、オルが一瞬だけフミの名を呼びかける |
| 2-2 Create「名前のない新顔」 | ツクネが必須項目の抜けた偽の住人を、検証なしで保存する | 本物の新顔ソラを正しく登録できない。新顔扱いされたフミも二重に登録される | `create` → 検証つきの `store` | ソラが正しい一行として加わる | 自分の行が二つあり、どちらが本物か分からない |
| 2-3 Update「古い住所」 | ヌリエが全員の住所を「ヌリエの家」に塗り替える | 宿守ダンの転居先を含め、全員の住所が同じになる | `edit` で対象を確かめ → IDを指定して `update` | 対象の行だけが直る | 両親の住所が戻り、両親がフミの家を思い出す |
| 2-4 Delete「二重の名前」 | ケシが重複を消すと言い、対象を絞らずに消そうとする | 2-2の偽の住人とフミの重複行が残っている | 控えと照合し、重複行のIDで `destroy` | 誤った行だけが消える。消しきる前に止める | ケシがフミの行の前でためらう。正しい一行が残り、章末の完全回復を待つ |

- 記録係のオルは名簿を管理する側なので、各幕の困りごとの当事者にしない。家族に忘れられた側の当事者はフミ。
- 2-2では重複を拒否するルールを教えない。既存の教材は、同じ名前でも主キーで区別できると教えている（`src/chapterTwoQuestions.ts`）。2-2は必須項目の検証、重複の見分けは2-4の照合で扱う。
- 2-4では「消えたものは戻らない」と一言入れる。destroyが取り消せる操作だと誤解させない。

## 物語

- **2-1冒頭**：四天王の記録卿グラフィウスが石灯の村を襲い、名簿を4つに裂く。遅れて着いた主人公は、逃げ遅れた記録係オルの孫フミを庇う。プロローグで主人公が救われた場面（`src/App.tsx` の「迫る影」）を反転させた構図にする。グラフィウスは「こいつらで十分だ」と言い残し、CRUD戦隊悪レンジャーが4人そろって名乗り口上をして登場する。口上の中で各自の担当（読む・増やす・直す・消す）を名乗る。
- **各幕の流れ**：担当のレンジャーが村を襲い、困りごとが生まれる → ダンジョンへ向かう → 祭壇で術を得る → 村へ戻ってレンジャーと戦う → 欠片を取り戻し、村が一部回復する。
- **幕の区切り**：「第二章 第二幕『名前のない新顔』」のような幕タイトルを表示し、回復した村の一部（明かりが戻る、人が話し始めるなど）を見せる。
- **章末**：グラフィウス本人と「正々堂々勝負しろ」の最終戦。現行の総合実習7問をこの戦いへ置き換える。勝つと名簿が復元し、村の記憶が完全に戻る。
- 四天王は第二章で一人だけ登場する。残る3人は後の章の題材（認証・認可など）に対応させる予定で、未設計。

## 学習と戦闘

- レンジャーの技を、初心者がやりがちなCRUDの誤りとして設計する。

| 担当 | 技 | 対応する誤り |
| --- | --- | --- |
| Read | 別人の記録を見せ、取り違えさせる（記録自体は変えない） | `show` で違うIDを引く、一覧と詳細の取り違え |
| Create | 必須項目の抜けた偽の住人を大量に書き込む | 検証のない `store` |
| Update | 村の全員の記憶を同じ内容に塗り替える | 条件のない一括更新 |
| Delete | 一人を消すつもりで村ごと消す | 対象を絞らない削除 |

- **解説**は戦闘中ではなく、ダンジョンの導線の中にゆったり置く。部屋の入口に1〜2画面の必須の解説、入り組んだ通路の脇道に任意の詳しい解説（石板や旅人）を置く。読んだ解説は学習設定から読み直せる。
- **第5室**（ダンジョン内の応用の関門）は残す。
- **レンジャー戦**はその幕の応用試験。名簿ではなく、レンジャーが荒らした**名簿以外の村の記録**を題材にする（候補：2-1灯り当番表、2-2宿の予約、2-3倉庫の在庫、2-4貸し出し記録）。欠片を盾にして村の別の記録を荒らす、という筋にする。「何が起きたか見抜く → 正しい操作を選ぶ」形で5問前後を出す。正解のたびに敵のHPを削る。必須で、不正解なら主人公のHPが減り、0になったら戦いの冒頭から再挑戦する。ゲームオーバーにはしない。
  - 各戦に、それまでに学んだ操作との見分け問題を1問以上入れ、正解の操作が1種類だけの戦いを作らない。2-1の戦いには「データは変わらない」と判断する問題を入れる。
  - 戦いの前に、題材の表を会話で一度見せる。不正解のときは、対応するダンジョンの解説を一行で示す。再挑戦では問題の順番を変える。
- **最終戦（グラフィウス）**：どの幕でも使っていない題材（現行の総合実習と同じ掲示板）で、七役割と「データは変わらない」の判断を混ぜて出す。章全体でCRUDを見分ける場にする。
- **術**：祭壇でその幕の術を得る。4つともMPを消費する魔法で、第一章の「見極め」と同じ枠に入る。術は戦闘の勝敗だけを助ける。学習記録には最初の回答だけを残す。
- **ケシのためらい**は、正解の手本として目立たせない。学者が「本当に必要だったのは対象を絞ることだ」と気づかせる程度に留める。

| 術 | 効果 |
| --- | --- |
| 真読の瞳《インデックス・アイ》 | 間違えた後に、見るべき行やコードを強調して示す（答える前のヒントにはしない） |
| 創世の盾《ストア・イージス》 | 1回分のダメージを防ぐ盾を作る |
| 運命改稿《アップデート・リライト》 | 間違えた答えを1回だけ選び直せる |
| 終焉の抹消《デストロイ・ゼロ》 | 敵がかけた妨害を消す |
