# 全ジャンルの追加・変更仕様ひな形

対象に必要な項目だけ埋める。画像・音・問題・保存処理の全てへ同じ入力項目を強制しない。

| 項目 | 記入する内容 |
|---|---|
| 目的 | 誰が何をできるようになるか、変更前後の例 |
| 分類 | 主ジャンル、対象の種類、用途、媒体、環境、状態 |
| 共通仕様 | 利用する規約・Skillと参照時点。どの規則が適用されるか |
| 固有情報 | 今回の対象だけが持つ内容、制約、変更してよい範囲 |
| 正本/登録先 | 実際に編集するファイル・定義・利用先。説明文へ数値を複製しない |
| 関連ジャンル | 世界・人物・学習・保存など、同時に確認する経路 |
| 互換性 | 既存ID・セーブ・採点・報酬・到達性への影響 |
| 検証 | 観察できる完了条件、テスト/実画面、未対応の範囲 |
| 担当 | 複数人なら編集するファイルと共有する登録先 |
| 履歴 | 完成後の実際の結果・採否・検証記録へのリンク |
