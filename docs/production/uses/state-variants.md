# 状態差分

扉の開閉、宝箱、衣装/表情、魔法による変化などの共通仕様。対象の基本絵と「変える部分」「変えない部分」を明示する。

原則として採用済みの元絵を参照編集し、輪郭・縮尺・足元・キャンバス・光源・材質を維持する。別生成で対象がずれた場合は同一cropを付けただけで一致したと判断せず、重ね合わせや実画面の切替で確認する。扉が開いた空間は本当に透明か、物理的に通れるかを別々に確認する。

固有情報は状態名、差分、遷移条件、維持する特徴、表示素材と切り出し。開閉を画像だけで進行条件と同一視しない。現在の扉は [memoryGates.ts](../../../src/quests/memoryGates.ts) の進行と [WorldScene.tsx](../../../src/WorldScene.tsx) の表示、画像は [memoryPropArt.ts](../../../src/world/memoryPropArt.ts)。宝箱は [chests.ts](../../../src/chests.ts) と [ChestSprite.tsx](../../../src/ChestSprite.tsx)。

対応状況：既存の扉・宝箱は実装あり。任意素材を状態名だけで自動切替する共通機構は未実装。遷移前後・再読み込み・再訪・復習で条件と絵が一致し、報酬が重複しないことを確認する。[扉の制作記録](../../art/memory-props-v2.md)は再利用の見本、個別の採否と条件は[履歴](../templates/record.md)へ記録する。
