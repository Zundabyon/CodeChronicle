# 環境素材

地形・建物・小物の共通制作仕様。分類、光源、視点、論理マス、材質、描き込みの基準は[art-direction](../../art-direction.md)が正本。この文書では用途から確認する条件を整理する。

| 用途 | 固有情報・確認事項 |
|---|---|
| 地形 | 地面の材質、環境タグ、継ぎ目、反復、境界、通行可否。隣接タイルと繋げて確認 |
| 建物 | 用途、構造、素材、入口、占有マス、手前/奥の重なり。屋根・入口・庇と衝突範囲を分離 |
| 小物 | 用途、材質、大きさ、環境、操作可能性。地面を置き換えず重ねる。泉などは操作位置を確保 |

環境タグ（草原・洞窟等）は分類と別。別環境へ展開する時も用途・接地点・通行契約を維持し、材質や配色など変える部分を指定する。透過物と地面タイルの背景条件を混同しない。原画寸法とファイル名が同じとは仮定しない。

登録は [catalog.ts](../../../src/world/catalog.ts) と [各Art定義](../world.md)。画像ファイルを追加するだけでは登録されない。atlasの実測矩形を維持し、配置はマップ側へ分離。扉・宝箱は[状態差分](state-variants.md)も確認する。

対応状況：既存renderer・地形型・prop型は定義で追加可能な範囲あり。新しい地形効果や操作種別は別途実装が必要。14地形ジャンルの全素材が揃っているとは扱わない。

既存の家・教会・家具と同じ表示倍率で比較し、光源、輪郭、材質の情報量を確認する。画像検査に加え、入口や会話位置への到達性も検証する。採用・不採用と実際のプロンプトは[履歴](../templates/record.md)に残す。
