# 歩行

キャラクター・敵・生物の移動中の見た目を制作する共通仕様。「主人公の歩行」という固有手順にしない。対応状況は規約あり、現行の方向付きシート再生は主人公向けの専用実装。

## 共通入力と用途別の条件

対象の固有設定、移動方法（人型二足・四足・飛行など）、必要方向、待機と歩行のコマ、実表示サイズ、足元/接地点、対応する再生側を確認する。方向とフレーム数を全生物へ一律に強制しない。

現行の人型向け制作見本は「4方向 × 左足・待機・右足の3コマ」。生成時の行・列・順序を明示するが、これはすべての対象に実装済みの設定スキーマではない。四足や飛行はその対象に必要な動作と再生方法を別に定める。

## 制作契約

- 同じ対象の体型、衣装、持ち物、光源、画素のまとまりを全コマで保つ。
- 各方向を本当に描き分ける。背面で顔を出さず、左右で装備や固有特徴が反転してよいかを確かめる。
- 歩行では脚・腕・体のポーズが変わる。静止絵の上下移動や回転だけを複数ポーズと呼ばない。
- 足元/接地点と縮尺を合わせ、停止時は待機へ戻す。武器・マント・翼・尾まで各コマ内へ収める。
- 透過原画を維持し、等間隔グリッドが生成されたと仮定せず実測する。全シートを同じ原画解像度へ強制縮小しない。

## 登録と確認

現在は [WorldCharacter.tsx](../../../src/WorldCharacter.tsx) と [characterArt.css](../../../src/characterArt.css) が主人公の3列×4行を読む。CSSの順序・方向・停止コマと生成物を合わせる。新しい人物へ展開する場合は対応する描画分岐や登録経路の実装が必要。

全方向の待機→歩行→停止、足滑り、欠け、コマ移行時の拡縮、モーション軽減を実画面で確認する。素材の見た目とゲーム上の移動可能範囲は別。移動判定・セーブ位置の変更をこの画像依頼へ含めない。

[主人公の過去の歩行記録](../../../public/sprites/hero-walk-art.txt)は実例。再利用時は青い髪や衣装など対象固有の語を[人物設定](../characters.md)へ差し替え、実際に渡した指示・実測値・確認結果は[履歴](../templates/record.md)へ残す。
