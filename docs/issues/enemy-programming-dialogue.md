# 全敵の名前・遭遇・撃破セリフを、かわいいプログラミングモチーフに揃える

## 目的

「バグスライム」のかわいらしさを基準に、すべての敵の名前、出会った時のセリフ、散り際のセリフをプログラミングに即したものにする。
用語を名前に付けるだけでなく、その用語の特徴を敵の仕草や性格に反映する。

## 方針

- 雑魚、ボス、教会の復習用、ボス後の魔法練習用をすべて対象にする。
- 雑魚は「用語＋魔物」を基本に、短く、かわいく、声に出して読めるセリフにする。
- ボスは少し威厳を残し、復習・練習の敵は励ます口調にする。
- 出会いで特徴を示し、散り際でその特徴に決着を付ける。
- プログラミング概念について誤解を招く説明は避ける。セリフはキャラクター表現であり、用語解説にはしない。
- 地域違いは地名を残し、同じ種類の名前・セリフを共有する。
- 今回変更するセリフは遭遇時と敵撃破時。攻撃名、待機、攻撃、被弾、敵勝利のセリフは対象外。

## 実装箇所と注意点

- `src/content.ts`：マップ上の敵名。`enemyKinds` の種類に沿って名前を揃える。
- `src/battleBanter.ts`：`intro` と `defeat` を上記案へ変更。`defeat` は敵の散り際で、主人公勝利時に表示される。
- 復習・魔法練習の敵名は生成箇所も確認して変更する。
- f4 はトレント、f6 はサソリ、f7 はヘビの外見なので、新しい名前もそれに揃える。
- 問題ごとの動的なセリフ生成は不要。種類ごとの固定セリフとして実装する。
