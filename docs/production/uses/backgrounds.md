# 背景

タイトル・物語・戦闘などの場面を描く共通仕様。背景は独立画像として制作し、操作・タイトル文字・重要な教材コードを焼き込まない。

共通入力は場面と物語上の意味、場所、時刻、視点、主要対象、縦横比、文字/UIの置き場、PC/スマホでの見せたい範囲、参照画像と役割。人物・建物の固有特徴と[共通美術基準](../../art-direction.md)を組み合わせる。

世界観を単に月や城だけで表すのではなく、その場面で何を感じてほしいかを構図へ落とす。確定していない物語を背景生成だけで公式設定にしない。画面用途によって視点を決め、ワールドの論理タイル寸法を背景全景へ適用しない。

登録先は用途の利用先。現在のタイトルは [TitleScreen.tsx](../../../src/TitleScreen.tsx) と [titleScreen.css](../../../src/titleScreen.css)、物語は [App.tsx](../../../src/App.tsx) のプロローグ、戦闘は [BattleStage.tsx](../../../src/BattleStage.tsx) 等。画像の比率を保ち、PC/スマホのcropと文字のコントラストを確認する。

対応状況：既存画面は用途ごとの実装あり。背景名だけで全画面を自動切替する共通レジストリはない。タイトルの実例は[知識の旅の記録](../../art/title-journey-v1.md)。採用判断は文字が乗った実画面で行い、実際の指示・参照・保存先・確認環境は[履歴](../templates/record.md)へ残す。
