# 敵のステータス一覧

正本は [enemyStats.ts](../../src/enemyStats.ts)（場所の段階×種類の補正）と [bestiary.ts](../../src/bestiary.ts)。この表は2026-11-20時点の書き出しで、数値を変えたら作り直す。ゲーム内ではメニューの「モンスター図鑑」で倒した敵の値が見られる。

- 主人公の攻撃力 = 2 + LV÷2（切り捨て）+ 武器。与ダメージ = 攻撃力 + 0〜1 − 敵の防御（最低1）
- 主人公の防御力 = LV÷2（切り捨て）+ 防具。被ダメージ = 敵の攻撃 ±1 − 防御（最低1）
- 敵のLVより3以上高いと経験値が減る
- 悪レンジャー・グラフィウス・ボスは問題数で勝敗が決まるため対象外
